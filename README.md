# Moqi pour Windows

Moqi ia dans sa propre fenêtre, sur ton ordinateur : tes conversations, tes
créations et ton compte Moqi.

**Télécharger : [moqi.fr/telecharger](https://moqi.fr/telecharger)**

Ce dépôt ne contient que les versions publiées de l'application. Elle se met à
jour toute seule : la version suivante se télécharge en fond et s'installe
quand tu fermes Moqi.

Une question : [moqi.fr/aide](https://moqi.fr/aide).
